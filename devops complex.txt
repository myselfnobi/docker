<body>
<form id="myForm">
    <h2>Event Registration</h2>

    <input id="name" placeholder="Full Name">
    <input id="email" placeholder="Email Address">
    <input id="phone" placeholder="Phone Number">

    <select id="gender">
        <option value="">Select Gender</option>
        <option>Male</option>
        <option>Female</option>
        <option>Other</option>
    </select>

    <input id="college" placeholder="College Name">
    <input id="dept" placeholder="Department">

    <select id="year">
        <option value="">Year of Study</option>
        <option>1st Year</option>
        <option>2nd Year</option>
        <option>3rd Year</option>
        <option>4th Year</option>
    </select>

    <select id="event">
        <option value="">Select Event</option>
        <option>Hackathon</option>
        <option>Workshop</option>
        <option>Technical Quiz</option>
    </select>

    <p id="error"></p>
    <p id="result"></p>

    <button type="submit">Register</button>
    <button type="reset">Reset</button>
</form>

<script>
document.getElementById("myForm").onsubmit = function(e) {
    e.preventDefault();

    let name = document.getElementById("name").value.trim();
    let email = document.getElementById("email").value.trim();
    let phone = document.getElementById("phone").value.trim();
    let gender = document.getElementById("gender").value;
    let college = document.getElementById("college").value.trim();
    let dept = document.getElementById("dept").value.trim();
    let year = document.getElementById("year").value;
    let event = document.getElementById("event").value;

    document.getElementById("error").innerText = "";
    document.getElementById("result").innerText = "";

    if (!name || !email || !phone || !gender ||
        !college || !dept || !year || !event) {
        document.getElementById("error").innerText =
            "Please fill in all fields.";
        return;
    }

    if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email)) {
        document.getElementById("error").innerText =
            "Enter a valid email address.";
        return;
    }

    if (!/^\d{10}$/.test(phone)) {
        document.getElementById("error").innerText =
            "Phone number must contain 10 digits.";
        return;
    }

    document.getElementById("result").innerText =
        "Registration Successful! Name: " + name +
        ", Email: " + email + ", Phone: " + phone +
        ", Gender: " + gender + ", College: " + college +
        ", Department: " + dept + ", Year: " + year +
        ", Event: " + event;
};

document.getElementById("myForm").onreset = function() {
    document.getElementById("error").innerText = "";
    document.getElementById("result").innerText = "";
};
</script>
</body>
</html>

5. Git Merge Conflict in README.md
AIM
To create two branches that modify the same line in README.md, merge them, resolve the merge conflict, and push the resolved changes to GitHub.
Software and Hardware Required
- Software: Git, text editor, GitHub.
- Hardware: Computer with 4 GB RAM.
Procedure
1. Create a repository and add README.md.
2. Commit the initial file.
3. Create two branches, feature-one and feature-two.
4. Modify the same line differently in each branch.
5. Merge the branches into main.
6. Resolve the conflict manually, commit, and push.
Git Commands
git init
echo "Student Management System" > README.md
git add README.md
git commit -m "Add README"

git switch -c feature-one


Replace the README content with:
Student Management System - Registration


git add README.md
git commit -m "Update README for registration"

git switch main
git switch -c feature-two


Replace the same line with:
Student Management System - Search


git add README.md
git commit -m "Update README for search"

git switch main
git merge feature-one
git merge feature-two


The second merge should produce a conflict because the same line has different changes.
Resolve the Conflict
Open README.md. It will contain something similar to:
<<<<<<< HEAD
Student Management System - Registration
=======
Student Management System - Search
>>>>>>> feature-two


Replace the conflict markers and text with a final version:
Student Management System
Features: Student Registration and Student Search


Then run:
git add README.md
git commit -m "Resolve README merge conflict"
git remote add origin https://github.com/YOUR-USERNAME/StudentManagementSystem.git
git push -u origin main


If the remote is already configured, omit git remote add origin.
Output
CONFLICT (content): Merge conflict in README.md
Automatic merge failed; fix conflicts and then commit the result.

[main ...] Resolve README merge conflict


The conflict is resolved, and the final README is committed and pushed to GitHub.

2. Initialize Git and commit the base project.
3. Create a book-registration branch and add book registration.
4. Commit the registration feature.
5. Create a book-search branch from main and add search functionality.
6. Commit and merge both feature branches.
7. View the commit history.
Program
Create index.html:

<!DOCTYPE html>
<html>
<head>
    <title>Library System</title>
</head>
<body>
    <h2>Library Management System</h2>
    <input id="book" placeholder="Book name">
    <button onclick="addBook()">Register Book</button>
    <input id="search" placeholder="Search book">
    <button onclick="searchBook()">Search</button>
    <p id="output"></p>

    <script src="script.js"></script>
</body>
</html>



Create script.js with the registration feature first:

let books = [];

function addBook() {
    let name = document.getElementById("book").value;

    if (name == "") {
        alert("Enter book name");
        return;
    }

    books.push(name);
    document.getElementById("output").innerText =
        "Book registered: " + name;
}



Then add the search feature on the other branch:

function searchBook() {
    let name = document.getElementById("search").value;

    if (books.includes(name)) {
        document.getElementById("output").innerText =
            "Book found: " + name;
    } else {
        document.getElementById("output").innerText =
            "Book not found";
    }
}



The second snippet is an additional function. Keep the registration code and add this function to the same script.js file.

git init
git add .
git commit -m "Create library system"

git switch -c book-registration
git add script.js
git commit -m "Add book registration"

git switch main
git switch -c book-search


Add the search function, then run:
git add script.js
git commit -m "Add book search"

git switch main
git merge book-registration
git merge book-search
git log --oneline --all


If a conflict occurs, combine the two functions in script.js, remove conflict markers, and commit the resolution.

[book-registration ...] Add book registration
[book-search ...] Add book search

Updating ...

6.Experiment: Explore Docker Commands for Content Management
AIM
To explore and perform various Docker commands for managing containers, images, volumes, and files, and understand how Docker is used for content management.
Software and Hardware Required
Software:
- Windows 10/11 or Linux
- Docker Desktop
- VS Code or Notepad
- Command Prompt / PowerShell
Hardware:
- Computer or laptop
- Minimum 4 GB RAM
- Internet connection
Procedure
1. Install Docker Desktop on the system.
2. Open Docker Desktop and start the Docker engine.
3. Open Command Prompt or PowerShell.
4. Check the Docker version.
5. Download a sample Nginx image from Docker Hub.
6. Create and run a container.
7. Explore Docker commands for managing images and containers.
8. Create a volume to store content.
9. Copy files between the host system and container.
10. Stop and remove the container.
Commands and Execution
1. Check Docker Version
docker --version


Displays the installed Docker version.

2. Download a Docker Image
docker pull nginx


Downloads the Nginx image from Docker Hub.

3. Display Docker Images
docker images


Lists all downloaded Docker images.

4. Create and Run a Container
docker run -d --name mycontainer -p 8080:80 nginx


Creates and runs an Nginx container in the background.

5. Display Running Containers
docker ps


Displays all running containers.

6. Display All Containers
docker ps -a


Displays running and stopped containers.

7. Copy Files into a Container
docker cp index.html mycontainer:/usr/share/nginx/html/


Copies an HTML file from the current directory into the container.

8. Create a Docker Volume
docker volume create myvolume


Creates a volume to store persistent data.

9. Display Docker Volumes
docker volume ls


Displays all available Docker volumes.

10. Inspect a Docker Volume
docker volume inspect myvolume


Displays detailed information about the volume.

11. View Container Logs
docker logs mycontainer


Displays the container logs.

12. Stop a Container
docker stop mycontainer


Stops the running container.

13. Start a Container
docker start mycontainer


Starts the stopped container again.

14. Remove a Container
docker rm -f mycontainer


Stops and removes the container.

15. Remove a Docker Image
docker rmi nginx


Removes the downloaded Nginx image if it is no longer being used.
